Title Cards

Builds each home-screen library image as a collage of that library's own artwork, with the library name drawn the way Jellyfin draws it. Cards refresh nightly (Scheduled Tasks > "Refresh title cards"); new views and libraries get a card shortly after they appear.

Users who turn title cards off see Jellyfin's own library images, refreshed by Jellyfin as usual. A user's choice applies in all their apps, including TV apps.

Per-user choices

Users can set this themselves in the web client under Settings > Display > Show title cards when the File Transformation plugin is installed. You can also set it for them here, with or without that plugin.

Skips artwork with logos or lettering where the title goes. Uses bundled text detection, available on Linux x64 and ARM64; on other platforms cards are built without this check.
Sports listings are usually team-logo graphics that clash with the title.
Album, book and audiobook covers fill their tile edge to edge, losing their top and bottom. When off, each cover is shown whole on a blurred copy of itself. Applies from the next refresh; run "Refresh title cards" to redraw existing cards now.
Changing Home > Library Folders creates a new combined view for that user; this gives it a card within about a minute instead of at the next scheduled check.
